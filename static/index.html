Gene expression grapher

Type a value or drag a slider. The graph updates as you go.

Dashed line: the paper's predicted average. Shaded band: predicted average ± 1 standard deviation (about two-thirds of the jagged line should fall inside).
Compare mode: press Keep this run, change a value, and both runs are drawn on the same axes. Up to 4 kept runs.
File format: one name = value per line, e.g. r = 1. Names: r, gamma_m, beta, gamma_p, t_max, and for feedback K, n, r_basal (feedback = 0 or 1 turns it off or on). Lines starting with # are ignored.
